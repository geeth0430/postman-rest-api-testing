# RESTful User API Testing

## 📌 Project Overview

A practical **REST API testing project using Postman** to demonstrate Software Quality Assurance and API testing skills.

## 🛠️ Tools

- Postman
- JavaScript
- Git
- GitHub
- Newman
- Excel

## 🎯 Testing Objectives

- Test REST API endpoints
- Validate HTTP status codes
- Validate JSON responses
- Perform positive and negative testing
- Create automated Postman assertions
- Execute API test cases
- Report defects
- Generate test reports

## 🌐 API Operations

| Method | Test |

| GET | Get Users |
| POST | Create User |
